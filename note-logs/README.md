# note-logs/ · 学生对话记录（自动化批分数据源）

这里存放学生完成「研究笔记」时与 AI 学习伙伴的对话原文，供**外部批分引擎**拉取。

## 读取接口（本站只读）

```
GET /note-log/1      # 研究笔记 1
GET /note-log/2      # 研究笔记 2
GET /note-log/3      # 研究笔记 3
```

- 命中：`200` + `note-logs/note-{x}.json` 的内容（原样 JSON）
- 文件不存在（学生还没完成该笔记）：`404 { "error": "note-logs/note-1.json 尚未生成" }`
- 编号不是 1 / 2 / 3：`400`
- 文件不是合法 JSON：`500`

批分引擎只需 GET 这三个地址，不需要登录态。

## 写入约定

- 文件名固定：`note-1.json` / `note-2.json` / `note-3.json`（与笔记编号对应）。
- **由 AI 学习伙伴在学生做完该笔记后写入**；本站服务不写入任何文件。
- 一位学生做多份笔记 → 多个文件（本轮按"一名学生一份笔记一个文件"处理；同班多人的情况由批分引擎按文件/目录拆分，命名可在本约定上扩展）。

## JSON 结构

```json
{
  "note": 1,
  "student": "张三",
  "class": "初二 3 班",
  "startedAt": "2026-10-08T20:15:00+08:00",
  "finishedAt": "2026-10-08T21:02:00+08:00",
  "messages": [
    { "role": "student", "content": "我想先用嘴的长度试试", "ts": "2026-10-08T20:16:12+08:00" },
    { "role": "ai", "content": "好的，先押注：你觉得多少毫米能分开阿德利和帽带？", "ts": "2026-10-08T20:16:20+08:00" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `note` | 笔记编号，1 / 2 / 3 |
| `student` | 学生标识（姓名或学号） |
| `class` | 班级，可选 |
| `startedAt` / `finishedAt` | ISO 8601 时间戳，可选 |
| `messages[].role` | `student`（学生说的）/ `ai`（AI 学习伙伴说的） |
| `messages[].content` | 该轮对话原文 |
| `messages[].ts` | 该轮时间戳，可选 |

批分引擎按 `role: "student"` 的消息数量、长度与内容评估思考深度；本仓库不实现批分。
