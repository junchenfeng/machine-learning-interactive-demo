## 第一章 · 研究问题

南极帕默站量过 **143 只企鹅**，每只都记了四个**特征**：
**嘴的长度、嘴的厚度、翅膀长度、体重**（单位分别是毫米、毫米、毫米、克）。

这 143 只里，**99 只是阿德利企鹅，44 只是帽带企鹅**（这就是要预测的**类别**）。

上一课我们自己挑阈值（分界线）、自己数对了多少只。这一课我们换个做法：
**不给电脑任何规则，只把 143 只企鹅和它们的正确类别交给它，让它自己学出一串"是不是"的问题。**

> **研究问题：让电脑自己学规则，能把这两种企鹅分开吗？参数取哪一组，分得最准？**

## 第二章 · 研究设计

一句话说清方法：**换不同的参数组合、各训练一棵决策树，用准确率当评价指标，挑出分得最准的那一棵；准确率打平时，取更简单的那一棵。**

| 要素 | 设计 |
|---|---|
| 样本（训练集） | 143 只（阿德利 99 / 帽带 44），**100% 用作训练，不划分测试集** |
| 特征 | 4 个特征（嘴的长度 / 嘴的厚度 / 翅膀长度 / 体重）一起交给模型，用哪个由它自己挑 |
| 模型 | 决策树：一串"是不是"的问题，每个节点只问一个特征 |
| 参数一 · **max_depth** | 树**最多问几层**问题（1 / 2）；网站 Tab 05 简写作 depth |
| 参数二 · **min_samples_leaf** | 每个**叶节点**（树最后的每一组）**最少装几只**企鹅（10 / 60）；网站 Tab 05 简写作 min-leaf |
| 要做的实验 | 两个参数各取两档 → **4 组参数组合，各训练一棵树** |
| 评价指标 | **准确率（accuracy）= 判对的只数 ÷ 143**，越大越好；再用**混淆矩阵**看它错在哪 |
| 准确率打平时 | **取更简单的模型**（树更浅、问的问题更少、叶节点更少）——这条原则叫**奥卡姆剃刀（Occam's razor）** |
| 基线（baseline） | 闭眼全猜"阿德利"（样本里最多的那个类别）＝ 99 ÷ 143 = **69.2%**；赢不了它就等于白做 |
